⚙️ About This Project

🔩
Hardware
ESP32 + MAX30102 + DS18B20 + SSD1306 OLED + Buzzer + LED
📡
Wireless
IEEE 802.11 b/g/n Wi-Fi, HTTP REST API (JSON), ThingSpeak cloud
💻
Firmware
Arduino framework on ESP32. Self-hosted web server on port 80
🔔
Alerts
LED + buzzer trigger on abnormal HR, SpO₂ or temperature readings
💰
Cost
₹600 – ₹900 total (~$8–$12 USD). Beginner friendly build.

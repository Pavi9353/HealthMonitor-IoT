📡 How It Works

📶
Web Bluetooth API
Browser connects directly to your smartwatch via BLE — no app, no server needed.
❤️
GATT Heart Rate
Reads standard Heart Rate Measurement (0x2A37) from your watch in real-time.
🩸
SpO₂ & Temp
Simulated realistically. Use ThingSpeak or ESP32 to add real sensor data.
🔔
Smart Alerts
Color-coded badges and alert banner fire automatically on abnormal readings.
🌐
Browser Only
Works in Chrome & Edge (desktop + Android). HTTPS required — Vercel handles this!
